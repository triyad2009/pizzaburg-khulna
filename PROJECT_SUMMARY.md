## 🚀 Deployment Options

### Recommended: Vercel
```bash
npm install -g vercel
vercel
```

### Alternative: Docker + Cloud Run
```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build
EXPOSE 3000
CMD ["npm", "start"]
```

### Self-Hosted: PM2 + Nginx
```bash
pm2 start npm --name pizzaburg -- start
```
